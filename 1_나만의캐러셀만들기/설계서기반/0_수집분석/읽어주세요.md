# 0_수집분석 — 미리 모아 둔 게시물과 분석

앤서니 팀이 다식약사(@dasik.yaksa) 공개 게시물을 모으고 **사실만** 분석한 자료다(게시물 그림, 캡션 통계, 그림 크기·색 실측, 글자 크기·여백 실측, 게시물 종류 판정). 부품 후보·대표 편 목록·디자인 설계 초안처럼 우리가 판단한 문서는 넣지 않았다 — 그 판단은 이 묶음의 클로드가 `1_공통설계서/설계하기.md`대로 새로 한다. 약사님이 게시물을 다시 모으지 않아도 되게 넣었다. **이 폴더의 파일은 원본이므로 고치지 않는다**(잘라 쓸 때는 복사해서 쓴다).

- 모은 날: 게시물 목록·캡션 **2026-10-30**(앱 안 브라우저, 비로그인 — 프로필 격자를 끝까지 내려 받음), 좋아요·게시일 일부와 슬라이드 그림 **2026-10-30·2026-11-02**. 그 뒤에 올라온 게시물은 없다.
- 공개 카드뉴스(캐러셀) 슬라이드와 캡션만 있다. 릴스·스토리·개인 게시물·따로 받은 본인 사진은 없다.
- 게시물 목록은 계정 전체 990개 중 최근 348개다. 캡션은 격자 글이라 약 1,070자에서 잘린 것이 있다.

## 편 폴더 이름 규칙

`게시물/<게시 날짜>_<아이디>/`
- 게시 날짜 = 한국 날짜(`YYYY-MM-DD`). 아이디 = 인스타 주소 `instagram.com/p/<아이디>/`의 그 글자.
- 안에 `1.jpg, 2.jpg …` = 받은 장 순서.
- `출처.json` = 주소·게시일·**`종류`**(분류.md와 같다)·장 수·받은 날·받은 방법·원본 해상도. 인스타 장 수보다 적게 받은 편은 `인스타_장수`·`메모`가 있다. `원본해상도`는 첫 장 기준이라 다른 장 크기와 다를 수 있다 — 장 크기는 그림을 열어 본다.
- **영상 장 미리보기는 없다**: 이 계정은 영상 장을 받지 않았다. 대신 DeF_DP0j0mI(8장 중 7장)·Ded_xOMkfV9(11장 중 10장)·De3-drHiZb6(8장 중 6장)은 장이 빠져 있고, 받은 그림에 1부터 차례로 번호를 붙였다(빠진 장이 몇 번째였는지 모름).
- **실명은 사본에서 가렸다**: 장 안에 본인 실명이 보이던 곳(문자·프로필 화면 캡처, 가운 이름 자수)은 이 묶음 사본에서 흐리게 가렸다. 편마다 `출처.json`의 `가린 곳`에 적었다. 가린 자리는 재지 않는다.
- `글.md`(장별 글을 받아 적은 것)는 `2026-10-24_De3-drHiZb6`에만 있다. 다른 장의 글은 그림을 열어 읽는다.
- 그림 크기는 편마다 다르다(1080×1350, 1320×1760, 1183×1578 등). 4:5가 대부분이고 3:4가 3편 — 편별 표와 쓰면 안 되는 장은 `3_작업안내/다식약사_작업안내.md` 1·2장.
- 종류는 `분류.md`가 기준이다(`출처.json`의 `종류`와 같다).

## 분석 문서 속 옛 경로 읽는 법

분석 문서는 우리 쪽 보관 폴더 이름으로 경로를 적었다. 이 묶음에서는 아래처럼 읽는다.

| 문서에 적힌 경로 | 이 묶음 안 자리 |
|---|---|
| `01/게시물목록.json`·`01_수집_인스타게시물/…`·`01/프로필.md` | `0_수집분석/게시물목록.json`·`프로필.md` |
| `02/슬라이드/<편>/`·`02_대표게시물_슬라이드/슬라이드/<편>/`·`…/참고_대표아님/슬라이드/<편>/` | `0_수집분석/게시물/<편>/`(두 곳을 한 폴더로 모음 — 개인 일상 1편은 넣지 않음) |
| `02/분류.md` | `0_수집분석/분류.md` |
| `03_분석_계정특징/2026-11-03_1단계_실측.md` 등(`2026-11-0n_` 머리) | `0_수집분석/1단계_실측.md`·`캡션통계.md`·`슬라이드실측.md` |
| 계정별메모·커스텀 설계서·정보형 모양표(우리가 쓴 설계 문서) | 묶음에 없음 — 이번에 약사님 쪽에서 새로 만든다(`7_결과/설계/`·`2_커스텀설계서/`) |
| `설계서/공통/작업_설계서.md`·`도구/…`(수집검증·캡션통계 도구 등)·`git-docs/…` | 묶음에 없음(우리 쪽 작업 문서·도구) — 필요 없다 |
| `한눈에보기/`, `_이전` 같은 옛 판, 검수 기록(`04_설계서검토/…`), `05_동의와설정/…`, `수집검증` | 묶음에 없음(넣지 않음) |
| 우리가 만든 디자인 시스템 화면·부품 견본·그림 조각·완성 캐러셀 | 묶음에 없음 — 이번에 약사님 쪽에서 새로 만든다 |

- 문서에 나오는 `계정A`~`계정G`(다식 = 이 계정 자신이라 이름 그대로)는 다른 약사님 계정 이름을 가린 것이다. "사용자"·"앤서니"·"제이"는 그룹스터디 진행자다.
- 분석 문서의 숫자(편 수·장 수)는 그 문서를 쓴 때 기준이라 서로 다를 수 있다(예: 슬라이드실측은 19편, 이 폴더 게시물은 31편 190장. 캡션통계의 "분류.md 기준" 종류 비율은 다시 본 50편 표만 센 것).
- 캡션통계·슬라이드실측의 `[도구]` 칸 안내, "대표 hex" 같은 말은 우리 쪽 도구가 쓴 말이다. "대표 hex"는 32단위로 뭉친 색 값이라는 뜻이고 대표 편과는 상관없다.
